Online Banking System (Python + MySQL)

Project Overview
The Online Banking System is a desktop-based application developed using Python and MySQL. The application uses Tkinter for the graphical user interface and MySQL for backend database management. It allows users to securely manage banking operations through an interactive and user-friendly dashboard.

Key Features
- Secure user login and authentication
- Customer dashboard with personal details
- Account management and balance viewing
- Deposit and withdrawal functionality
- Transaction history tracking
- Loan management (apply and repay loans)
- Card management with masked card details
- Bill payment module
- Real-time date and time display

Technologies Used
- Python
- Tkinter (GUI)
- MySQL
- mysql-connector-python
- Pillow (PIL)
- Visual Studio Code

Database Design
The system uses a relational MySQL database with tables such as Customer, Account, Transaction, Loan, Card, and BillPayment. Primary and foreign keys are used to maintain data integrity and proper relationships between entities.

Application Flow
Users log in with valid credentials, access the dashboard, and navigate through various banking modules. All operations such as deposits, withdrawals, and payments are dynamically updated in the database.
